Pixel coordinates for rows and columns of the board on the LCD screen.  


Pixel coordinates for rows and columns of the board on the LCD screen. 

These values define the X and Y positions for the columns and rows of the board. The origin is at the top left of the screen, so Column 1 is the leftmost column, and Row 1 is the top column
