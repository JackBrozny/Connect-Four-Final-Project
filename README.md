# Connect Four – Embedded Software Engineering Final Project

A Connect Four game implemented in C for the STM32F429I Discovery Board. This is my final project for my Embedded Software Engineering class, and I applied the skills I learned over the course of the semester like using SPI, interrupts, reading technical documentation, etc.

[Code Documentation](https://your-username.github.io/your-repo/Code_Documentation/index.html)

---

## Features

-  Gameplay loop with 1-player and 2-player modes
-  Visual game board on LCD touchscreen control
-  AI opponent using the STM32 RNG peripheral
-  Game over win/tie detection
-  Post-game summary screen with time and scores
-  Modular design and Doxygen documentation

---

##  Applied Concepts

- STM32 HAL drivers (touch, LCD, RNG)
- Interrupts and polling
- Real-time event handling
- LCD pixel mapping and coordinate conversion
- Doxygen documentation generation
