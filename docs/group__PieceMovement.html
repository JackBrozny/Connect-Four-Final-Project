void Board_DropPiece ( )

Drops the piece into column it's hovering over.

This function iterates down each row until it reaches a filled slot and then places the piece on the row above it. It checks for a win or a tie, makes it the other player's turn, and resets the hovering piece.

◆ Board_SetHoveringPiece()

void Board_SetHoveringPiece ( )

Sets hovering piece at center column.

This function sets the position of the hovering piece to the middle column and displays a red or blue piece on the LCD screen depending on which player's turn it is.

◆ Board_ShiftHoveringPieceLeft()

void Board_ShiftHoveringPieceLeft ( )

Moves hovering piece one column to the left.

This function changes the stored data of the hovering piece to one column to the Left. If the piece is on the furthest Left column, it does nothing.
