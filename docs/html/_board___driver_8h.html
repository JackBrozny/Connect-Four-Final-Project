◆ Board_PlayPolling()

void Board_PlayPolling ( )

Gameplay polling loop.

This function enters a polling loop that occurs for the entire game. It checks for touch screen input to move the hovering piece right or left and only breaks when the isStillPlaying flag is changed to signify the game has ended.
